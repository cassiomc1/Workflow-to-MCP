# Security policy

Workflow to MCP is a local-first MVP. Do not expose its runtime as an unauthenticated network service or run unreviewed workflows against production accounts. See [security model](docs/security-model.md) for trust boundaries, restrictions and regression coverage.

Report suspected vulnerabilities privately to the repository owner through the repository security-advisory mechanism if available. Do not include credentials, private recordings, raw browser profiles or production data. Include the affected version/hash, minimal synthetic reproduction, expected policy and observed behavior. No response SLA or independent security certification is claimed.
